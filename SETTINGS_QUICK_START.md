# ⚙️ Instellingen - Quick Start Guide

## 🚀 Toegang tot Instellingen

1. Start je dashboard: `npm run dev`
2. Klik op **⚙️ Instellingen** in de navigatiebalk
3. Pas instellingen aan naar wens
4. Alles wordt automatisch opgeslagen!

## 🎯 Top 3 Meest Gebruikte Instellingen

### 1️⃣ Geluid Aan/Uit
```
Instellingen → Audio Instellingen → Audio Alerts toggle
```
**Perfect voor**: 's Nachts werken zonder alarm

### 2️⃣ Temperatuur Waarschuwingen
```
Instellingen → Temperatuur Drempelwaarden → Sliders aanpassen
```
**Perfect voor**: Striktere of soepelere monitoring

### 3️⃣ Update Snelheid
```
Instellingen → Display Instellingen → Sensor Update Interval
```
**Perfect voor**: Real-time (5s) of performance mode (5m)

## ⚡ Snelle Acties

| Wat wil je? | Actie |
|-------------|-------|
| **Geen geluid** | Instellingen → Zet beide audio toggles UIT |
| **Agressievere alerts** | Verlaag beide temperatuur drempels |
| **Battery saving** | Verhoog update interval naar 5 minuten |
| **Maximum detail** | Verhoog datapunten naar 120 en incidents naar 100 |
| **Test alarm** | Scroll naar Audio → Klik "Test Alarm Geluid" |
| **Reset alles** | Scroll naar beneden → "Reset naar Standaard" 2x klikken |

## 🔧 Troubleshooting

### Alarm speelt niet af
1. Check of "Audio Alerts" is ingeschakeld
2. Klik "Test Alarm Geluid" knop
3. Controleer browser audio permissions
4. Verhoog volume percentage

### Instellingen verdwijnen
- Controleer of browser cookies/localStorage enabled is
- Incognito mode wist instellingen bij sluiten

### Dashboard reageert traag
- Verhoog "Sensor Update Interval"
- Verlaag "Grafiek Datapunten" naar 30

## 💡 Pro Tips

1. **Test altijd eerst**: Gebruik de "Test Alarm" knop voordat je live gaat
2. **Kleine stappen**: Pas één instelling tegelijk aan
3. **Monitor prestaties**: Lagere intervals = meer CPU gebruik
4. **Backup**: Noteer je favoriete instellingen voor later
